# AI-Powered Chatbot with Custom LLM & ML Model

An intelligent chatbot developed using Machine Learning, Natural Language Processing (NLP), and Large Language Models (LLMs). The system is capable of understanding user queries, identifying intents, and generating context-aware responses.

## Features

* Intent classification using a custom-trained ML model
* Natural language understanding and response generation
* REST API integration
* Data preprocessing and model training pipeline
* Domain-specific query handling

## Tech Stack

* Python
* Machine Learning
* NLP
* LLM Integration
* REST APIs
